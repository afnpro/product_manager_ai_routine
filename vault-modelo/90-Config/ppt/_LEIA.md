# Template de apresentação

1. Coloque aqui o arquivo de apresentação da empresa (`.pptx` ou `.potx`). Um arquivo só.
2. Rode `/configurar-template` no Claude Code.
3. O comando gera `mapa-layouts.md` nesta pasta, dizendo qual layout usar para capa, seção, conteúdo, duas colunas, gráfico, tabela e encerramento.

Todos os comandos que geram PPT (`/status`, `/demo`, `/roadmap`, `/metricas`, `/ppt`) usam esse mapa. Se trocar o template, rode `/configurar-template` de novo.

O template não sai do seu computador.
