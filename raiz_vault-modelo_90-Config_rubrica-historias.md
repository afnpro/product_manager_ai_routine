# Rubrica de histórias

> Ainda não configurada. Rode `/configurar-rubrica` depois de colocar as regras em `90-Config/rubrica-fontes/`.
> Enquanto isso, o `/historias` usa apenas os critérios genéricos abaixo e avisa que a nota não é estimável.

## Critérios genéricos (INVEST + critérios de aceite)

| Critério | Pergunta de verificação |
| --- | --- |
| Independente | Pode ser entregue sem depender de outra história da mesma sprint? |
| Negociável | Descreve o problema e o valor, sem fixar a solução técnica? |
| Valiosa | O "para que" deixa claro o ganho para o usuário ou para o negócio? |
| Estimável | O time tem informação suficiente para estimar? |
| Pequena | Cabe em uma sprint? |
| Testável | Todos os critérios de aceite são verificáveis (Dado/Quando/Então)? |
